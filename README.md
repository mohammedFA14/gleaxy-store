# Galaxy Store

متجر ألعاب ومنتجات رقمية بواجهة عربية. الطلبات والمنتجات والأقسام والإعدادات تنحفظ في ملف `data/store.json`، والصور اللي ترفعها من لوحة الإدارة تنحفظ داخل `data/uploads/`. ما يحتاج Firebase.

## تشغيل المتجر

```sh
npm install
npm run dev
```

افتح رابط Vite الظاهر بالترمينال. الأمر يشغل واجهة المتجر وخادم البيانات المحلي معاً. للإنتاج ابنِ الواجهة ثم شغل `npm start` مع `NODE_ENV=production`.

## دخول الإدارة

حط `ADMIN_EMAIL` و`ADMIN_PASSWORD` بملف `.env` الموجود بجانب `package.json`. ملف `.env` خاص بالخادم وما ينرسل للمتصفح. افتح `/admin` وسجل دخولك بالإيميل وكلمة المرور. رابط الإدارة غير ظاهر للزبائن.

## إدارة المتجر

- عدّل اسم المتجر، نص البداية، الشعار، واتساب وتيليجرام وديسكورد من تبويب **إعدادات المتجر**.
- عدّل وسائل الدفع، أرقام التحويل، وأظهر أو أخفِ أي طريقة.
- أضف الأقسام والمنتجات، وارفع صورها من الجهاز. الصور الجديدة تروح إلى `data/uploads/` وروابطها تنحفظ بملف المتجر.
- الطلبات والنشاط وحالات الطلب تنحفظ في `data/store.json`.
- حسابات الزبائن تنحفظ في `data/accounts.json`، وكلمات المرور مخزنة كـ hash مملح. التقييمات تنحفظ في `data/reviews.json`.
- الزبون يقدر ينشئ حساباً بالإيميل وكلمة المرور مع رقم هاتف اختياري، ويقدر يكتب تقييماً من 1 إلى 5 للمتجر أو لأي منتج. إدارة الحسابات والتقييمات من تبويبي **الحسابات** و**الآراء**.
- من صفحة **حسابي** يشوف الزبون طلباته وحالتها ورسائل الإدارة. الطلبات الجديدة ترتبط بالحساب إذا كان الزبون مسجل دخول وقت إكمال الطلب؛ طلبات الضيف لا تظهر في سجل الحساب.
- تغيير حالة الطلب يضيف رسالة تلقائية مناسبة، وتقدر الإدارة تكتب تحديثاً خاصاً لكل طلب من لوحة **الطلبات**.
- لتفعيل Google أضف `GOOGLE_CLIENT_ID` إلى `.env`، وأنشئ Web OAuth Client في Google Cloud وأضف `http://localhost:5173` إلى Authorized JavaScript origins. اتركه فارغاً لإخفاء خيار Google. تسجيل الهاتف عبر رمز SMS يحتاج مزود رسائل؛ رقم الهاتف حالياً حقل اختياري بملف الحساب.
- زر **نسخة احتياطية** ينزّل نسخة JSON من بيانات المتجر.

احتفظ بنسخة احتياطية من مجلد `data` حتى ما تضيع البيانات عند نقل المشروع إلى جهاز أو خادم آخر، بما فيها ملفات الحسابات والتقييمات.
